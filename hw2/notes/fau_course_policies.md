# COT5930 Course Guidelines and Assignment Protocols

This document outlines standard policies, grading rubrics, and submission workflows for Florida Atlantic University (FAU) COT5930: Generative AI and Security Systems Engineering.

## Student Identification & Screenshot Standards

### FAU ID Requirement
All student submissions, screenshots, and screencasts must prominently feature the student's FAU ID:
- Student ID: `Z23875984`
- Terminal prompt: Configured to display `Z23875984@mac`
- Antigravity IDE Title: Permanent configuration via `${rootName} - ${activeEditorShort} - Z23875984`

## Homework Deliverables

### Repository Structure
Each assignment repository follows a standardized directory structure:
- Root directory contains configuration files (`.gitignore`, `.env` for local secrets, and `README.md`).
- Specific assignment folders such as `hw2/` contain application code (`app.py`), screencast links (`screencast_url.txt`), and local knowledge stores (`notes/`).

### Version Control Protocols
Students must make frequent, atomic commits with conventional commit messages (e.g., `feat:`, `fix:`, `refactor:`) and push changes directly to `origin main`.
